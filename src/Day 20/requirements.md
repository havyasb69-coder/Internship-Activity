# Requirements

This document lists the Python packages required to run the **Customer Analytics EDA** project, including the Jupyter notebook and supporting scripts.

## Core Packages

- `pandas` >= 1.3.0 – data manipulation and analysis
- `numpy` >= 1.21.0 – numerical computing
- `matplotlib` >= 3.4.0 – plotting and visualisation
- `seaborn` >= 0.11.0 – statistical data visualisation
- `jupyter` >= 1.0.0 – to run the notebook
- `python-pptx` >= 0.6.21 – for generating PowerPoint presentations (optional)
- `openpyxl` >= 3.0.9 – for Excel file handling (optional)

## Installation

Install all required packages using `pip`:

```bash
pip install pandas numpy matplotlib seaborn jupyter python-pptx openpyxl
